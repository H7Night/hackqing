# 云麦 / 好轻 体脂秤 BLE 协议（YUNMAI-Scale-3）

本文由 `com.yunmai.scale` v5.6.4 反编译 + 真机日志逐字节核对得到。

## 1. GATT

好轻按 **UUID 子串**匹配特征（见 `zy.a0`，字段 `f145714d/e/f`）：

| 用途 | 子串 | 完整 UUID |
|---|---|---|
| 写（手机→秤） | `0000ffe9` | `0000ffe9-0000-1000-8000-00805f9b34fb` |
| 读/通知（秤→手机） | `0000ffe4` | `0000ffe4-0000-1000-8000-00805f9b34fb` |
| WiFi 读 | `0000ffe6` | `0000ffe6-...` |

连接后：开通知 → `requestMtu(75)` → 发送握手序列。

## 2. 帧格式

收发同一套布局：

```
byte0  = 0x0D
byte1  = 总长度（整帧字节数）
byte2  = 命令
byte3  = 版本/类型
byteN  = 校验 = XOR(byte1 .. byte(len-2))
```

## 3. 手机 → 秤

| 命令 | 含义 | 帧样例 |
|---|---|---|
| `0x10` | 用户信息（18B） | `0D121003070B2775A90112555A1A580303A8` |
| `0x11` | 时间同步 | `0D0D116ACCE5C414000070807F` |
| `0x13` | 握手起始 | `0D05130016` |
| `0x14` | 收到最终结果回执 | `0D041410` |
| `0x17` | 查询设备时间 | `0D041713` |
| `0x18` | — | `0D04181C` |
| `0x40` | 抱婴模式 | `0D05400043` |
| `0x41` | 小物模式 | `0D0541.. ..` |
| `0x42` | 查询序列号 | `0D044246` |
| `0xF0` | 查询固件 | `0D05F000F5` |

### 3.1 用户信息帧 `0x10`（`bz.a.i`）

```
0D 12 10 <type> <uid:4> <身高> <性别> <年龄> <腰围> <胸围> <体重×100:低2字节> <单位> <体型> <ck>
```

- `type`：1=新增/更新，2=删除，3=新增或查询（连接握手用 3）
- 性别：1=男 2=女；单位：1=kg 2=lb 3=斤
- 年龄 <18 时写 0；身高/腰围/胸围为厘米整数
- 实测：`0D 12 10 03 070B2775 A9 01 12 55 5A 1A58 03 03 A8`
  → uid=118171509, 身高=169, 性别=1, 年龄=18, 腰围=85, 胸围=90, 基准体重≈67.44kg, 单位=斤, 体型=3

### 3.2 时间同步帧 `0x11`（`bz.a.j`）

```
0D 0D 11 <epoch:4 大端> 14 <时区符号> <时区:3 大端> <ck>      # 13 字节
```
- 时区秒数绝对值放低 3 字节；符号：负数时 byte8=0x80 否则 0x00
- UTC+8 → `00 70 80`（28800）
- 实测：`0D 0D 11 6ACCE5C4 14 00 007080 7F`

## 4. 秤 → 手机（通知）

| 命令 | 含义 |
|---|---|
| `0x01` | 实时体重 |
| `0x02` | 最终结果 |
| `0x03` | 秤用户列表 |
| `0x04` | 用户数已满 |
| `0x05` | 鉴权请求 |
| `0x06` | 用户信息 / 设备信息 |
| `0x07` | 设备时间 |
| `0x08` | 设备电量 |
| `0x40` | 抱婴模式 |
| `0x41` | 小物模式 |
| `0x42` | 序列号 |
| `0xF0` | 固件信息 |
| `0xA1` | 全局配置 |

### 4.1 最终结果帧 `0x02`（`cz.g.b`）

```
byte0   0x0D
byte1   协议版本（本机 = 0x21 = 33；>=30 表示含阻抗/体脂；==35 有额外字段）
byte2   长度
byte3   0x02
byte4   标志
byte5..8    Unix 时间戳（大端，秒）
byte9..12   用户 ID（大端）
byte13..14  体重 ×100（大端）
byte15..16  阻抗（大端）
byte17..18  体脂率 ×100（大端，版本 >=30）
byte19..    版本 35 扩展（含心率等）
last    校验
```

实测样例：

| hex | 体重 | 阻抗 | 体脂 | 备注 |
|---|---|---|---|---|
| `0D211402006ACCE526070B27751A59015706C2DD` | 67.45 | 343 | 17.30% | 完整 |
| `0D211402016ACCE4FB070B27751A590000000092` | 67.45 | — | — | 只出体重 |
| `0D211402016ACCE4CF070B27751A59015E06C23D` | 67.45 | 350 | 17.30% | 渐进更新 |

> 测量过程中会连续推送多帧最终结果，字段逐步补齐；最后一次为完整值。

### 4.2 实时体重帧 `0x01`（`dz.l.Z`）

体重要读取 **字节 [8..9]（大端 ×0.01）**；当 `byte1 == 35` 且长度 ≥24 时 `byte10==1` 表示正在测心率。

## 5. 连接时序（来自好轻日志 `ScaleCheck.log`）

```
[连接]
0D05130016                                    (0x13)
0D1210 03 <uid...>                            (0x10 用户信息)
0D041713                                      (0x17)
0D0D11 <epoch> 14 00 007080 <ck>              (0x11)
0D044246                                      (0x42)  → 收到 "返回设备序列号：BSS281W229106112"
0D05F000F5                                    (0xF0)  → 收到 "返回固件信息"
0D04181C                                      (0x18)
[测量中]  收到 0x01 实时体重(每秒多帧)
[测量结束] 收到 0x02 最终结果(可能多帧) → 回 0D041410
[绑定完成] 再次下发 0x10（更新基准体重）
```

天平上报 `0x08` 电量、`0x07` 时间、`0x06` 用户信息、`0x05` 鉴权等。
